## Current research focus

Align Arabic manuscript line images with their corresponding text using learned visual representations and differentiable sequence alignment.

## Suggested note structure

- `Architecture.md` — model components and design decisions
- `Experiments.md` — training runs, configurations, and observations
- `Results.md` — quantitative metrics and qualitative findings
- `Meetings/` — meeting notes and action items
- `Ideas/` — research questions and future experiments

## Workflow

1. Pull the latest repository changes before editing notes.
2. Record experiment commands, configuration changes, and outcomes.
3. Commit and push note changes with the source-code changes they describe.
